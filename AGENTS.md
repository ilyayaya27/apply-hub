# Заметки для AI-агента (Claude Code и совместимые)

Это **автокликер для hh.ru** (форк `hh-applicant-tool`, менторская программа IT Птица).

## Как управлять кликером
**Используй скил `hh-clicker`** — `.claude/skills/hh-clicker/SKILL.md`. Это пошаговый плейбук: установка с нуля, авторизация, AI-письма (бесплатный Groq или OpenRouter), рассылка откликов, ответы в чатах, поднятие резюме, проверенная стратегия и типичные грабли.

## Документация
- **`GUIDE.md`** — человеческая инструкция (быстрый старт — вверху).
- **`CHANGELOG.md`** — что менялось по датам.

## 🥇 Главное правило
**Перед любой массовой рассылкой — `--dry-run`.** Реальные отклики уходят живым работодателям и не отзываются. Сначала покажи пользователю, что улетит.

## Запуск
Из корня проекта через venv: `.venv/bin/python -m hh_applicant_tool <команда>`.
